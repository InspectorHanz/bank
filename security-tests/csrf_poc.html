This page demonstrates CSRF against customer/profile.php on the deliberately-vulnerable Aurelia Bank demo app. It does nothing on its own — it only fires if you already have an authenticated session with the target site open in this same browser.

CSRF demo — "personal details" update

How to use this for the course demo:

  1. In this browser, log in to https://aurelia-bank.infinityfree.io/auth/login.php as a customer (e.g. jdoe).
  2. Keep that tab open (or just stay logged in), then open this HTML file directly from disk in a new tab of the same browser — this simulates the victim visiting an attacker-controlled page while already logged in.
  3. The form below submits itself automatically. If your browser blocks the auto-submit, click the visible fallback button.
  4. Go back to the profile page (https://aurelia-bank.infinityfree.io/customer/profile.php) and refresh — the full name and email have changed, even though you never submitted that form yourself.
